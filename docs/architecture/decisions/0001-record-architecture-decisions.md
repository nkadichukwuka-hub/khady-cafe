# 1. Record architecture decisions

Date: 2026-09-10

## Status

Accepted

## Context

We want a lightweight record of significant technical choices so future
contributors understand why the project is built the way it is.

## Decision

We will keep Architecture Decision Records (ADRs) as numbered Markdown files in
`docs/architecture/decisions/`. Each ADR has: Status, Context, Decision,
Consequences. Superseded ADRs stay in place and link to their replacement.

## Consequences

- Small ongoing effort to write an ADR when a notable decision is made.
- Clear history of why things are the way they are.
