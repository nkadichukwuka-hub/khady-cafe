# Product Overview

## Vision

Khady's Café is a website for a neighborhood café. It should let visitors learn
about the café, browse the menu, and find location and hours — and eventually
place orders or reservations.

## Target users

- Local customers checking hours, location, and today's menu.
- New visitors deciding whether to come in.
- Café staff updating menu and content.

## Goals

- Fast, mobile-first pages that load well on phones.
- Menu that is easy for staff to keep current.
- Clear location, hours, and contact information.

## Non-goals (for now)

- Full e-commerce / delivery integration.
- Multi-location support.
- User accounts.
