# Khady's Café — Documentation

This folder holds project documentation: product decisions, architecture notes,
and operational guides.

## Contents

- `product/` — what we're building and why
  - `overview.md` — vision, target users, goals
  - `requirements.md` — features and acceptance criteria
- `architecture/` — how the system is built
  - `overview.md` — stack, structure, key decisions
  - `decisions/` — Architecture Decision Records (ADRs)
- `guides/` — how to work on the project
  - `getting-started.md` — local setup and common commands

## Conventions

- One topic per file. Keep pages short and current.
- Record notable technical choices as an ADR in `architecture/decisions/`.
- Link between docs with relative paths.
